# 📰 News IDCamp

News IDCamp is the final project for the Dicoding class "Getting Started with Flutter Application Development". This application is designed to display dummy news with an attractive and user-friendly interface.

## 🚀 How to Run the Application

1. Ensure you have installed the Flutter SDK and set up the environment
2. Clone this repository
   ```bash
   git clone https://github.com/ahmadazizfauzi/news_idcamp
4. Navigate to the project directory
   ```bash
   cd <project_name>
6. Install the dependencies
   ```bash
   flutter pub get
7. Run the application
   ```bash
   flutter run
